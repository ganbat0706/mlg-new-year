# Monlogistics шинэ жилийн урилгын веб тоглоом — Дизайн

**Огноо:** 2026-11-18
**Төлөв:** Хянуулахаар бэлэн

## 1. Зорилго

Monlogistics Group-ийн шинэ жилийн арга хэмжээний урилгыг ажилтнуудад
хөгжилтэй байдлаар хүргэх. Ажилтан веб дээр бүртгүүлж, богино тоглоом
тоглоно. Тоглоом дуусмагц хувийн дугаартай урилга үүсч, зураг хэлбэрээр
татагдана. Эхний байруудад орсон ажилтнууд арга хэмжээн дээр шагнал авна.

**Амжилтын шалгуур:**

- 100-200 ажилтан бүртгүүлж тоглох боломжтой
- Ажилтан бүр урилгаа гар утсан дээрээ зургаар авна
- Урилга бүр давхардахгүй дугаартай
- Оноо шударга — browser талаас хуурамчаар оноо нэмэх боломжгүй
- Арга хэмжээний өдөр техникийн эрсдэлгүй (урьдчилж бүгд тоглосон байна)

**Хамрах хүрээнд ОРООГҮЙ:**

- Шууд (live) олон хүн зэрэг өрсөлдөх горим
- Имэйл илгээх
- Ажилтны жагсаалттай систем холбох (HR/ERP)
- Нэвтрэх нэр, нууц үг

## 3. Хэрэглэгчийн урсгал

```
[1] Нүүр          Баннер + "Тоглож урилгаа ав"
[2] Бүртгэл       Овог · Нэр · Хэлтэс · Утас
                  Давхардвал: "Үлдсэн оролдлого: N" гээд үргэлжилнэ
[3] Дүрэм         Богино заавар + "Эхлэх"
[4] Quiz          10 асуулт × 10 секунд
[5] Reaction      20 секунд "Ачаа ачих"
[6] Үр дүн        Нийт оноо, leaderboard байр, "Дахин тоглох (N үлдсэн)"
[7] Урилга        MLG-202601 кодтой урилга + "Татаж авах"
```

Урилгын код **эхний бүртгэлд нэг удаа** үүснэ. Дахин тоглоход код
өөрчлөгдөхгүй, зөвхөн хамгийн сайн оноо шинэчлэгдэнэ.

Бүртгүүлсэн ажилтан урилгаа дахин авахыг хүсвэл утасны дугаараа оруулаад
`/invite/[code]` хуудас руу очно.

### 3.1 Бүртгэлийн талбарын шалгалт

| Талбар | Дүрэм |
|---|---|
| Овог | **Зөвхөн кирилл үсэг** (`/^[А-ЯӨҮЁа-яөүё\s-]+$/`), 2-50 тэмдэгт |
| Нэр | **Зөвхөн кирилл үсэг**, 2-50 тэмдэгт |
| Хэлтэс | Урьдчилан бэлдсэн жагсаалтаас сонгоно (`docs/departments-draft.md`) |
| Утас | 8 оронтой тоо, `8` эсвэл `9` -өөр эхэлнэ |

Латин үсэг оруулвал: *"Овог нэрээ кирилл үсгээр бичнэ үү"*. Шалгалт
client болон server хоёр талд хийгдэнэ (server нь эцсийн эрх мэдэлтэй).
Нэрийг хадгалахын өмнө илүүдэл зай арилгаж, эхний үсгийг томоор болгоно.

### 3.2 Тоглоом хаагдсаны дараа

`2026-12-03 23:59`-өөс хойш нүүр хуудас руу орсон хүн **шууд үр дүнгийн
хуудас руу** шилжинэ. Тэнд харагдах зүйлс:

- Эхний 5 байр — шагнал авах ажилтнууд, тодруулан харуулна
- Бүрэн leaderboard (бүх оролдсон хүн, оноогоор эрэмбэлсэн)
- Өөрийн байр, оноо, урилгын код (утсаа оруулаад хайна)
- Арга хэмжээний мэдээлэл: **2026-12-05**, цаг, байршил
- Урилгаа дахин татах товч

Бүртгэл ба тоглоомын API-ууд энэ үеэс хойш `410 Gone` буцаана.
Хаагдах огноо `GAME_CLOSES_AT` орчны хувьсагчаар тохируулагдана.

## 4. Тоглоомын механик ба оноо

### 4.1 Quiz

- Асуултын сангаас (15) санамсаргүй 10 асуулт сонгоно
- Хариултын дарааллыг оролдлого бүрт холино
- Асуулт тус бүр 10 секунд
- **Зөв хариулт = 100 оноо + (үлдсэн секунд × 10)**
- Дээд оноо: **2,000**
- Хугацаа дуусвал 0 оноо, дараагийн асуулт руу автоматаар шилжинэ

Асуултын агуулга: компанийн түүх, салбарууд, логистикийн нэр томьёо,
шинэ жилийн хөгжилтэй асуултууд. Төсөл: `docs/questions-draft.md`.

**Тэмдэглэл:** 15-аас 10 сонгоход 3 оролдлогын хооронд асуулт нэлээд
давтагдана. Сангийн хэмжээг 20-25 болговол давталт мэдэгдэхүйц буурна —
энэ нь зөвхөн өгөгдөл нэмэх асуудал, код өөрчлөгдөхгүй.

### 4.2 Reaction — "Ачаа ачих"

- Үргэлжлэх хугацаа: 20 секунд
- Дэлгэц дээр объект гарч ирээд 1.2 секунд байрлана
- **Ногоон контейнер дарвал: +40**
- **Улаан эвдэрсэн ачаа дарвал: −25**
- Нийт оноо 0-ээс доош буухгүй
- Дээд оноо ойролцоогоор **2,000** (тохируулж тэнцвэржүүлнэ)

Spawn хуваарь: сервер оролдлого эхлэхэд объект бүрийн гарах цаг, байрлал,
төрлийг урьдчилан үүсгэж өгнө.

### 4.3 Нийт

**Нийт оноо = Quiz оноо + Reaction оноо** (дээд тал нь ≈ 4,000)

Тэнцсэн тохиолдолд эрт дуусгасан нь дээгүүр байрлана.

**Эхний 5 байр** арга хэмжээн дээр шагнал авна.

## 5. Шударга байдлын хамгаалалт

1. **Оноог зөвхөн сервер тооцно.** Browser-оос ирсэн оноонд огт итгэхгүй.
2. **Quiz хурд серверт хэмжигдэнэ.** Асуулт үзүүлсэн цаг (`served_at`)
   серверт бичигдэнэ, хариулт ирэхэд зөрүүг сервер тооцно.
3. **Reaction баталгаажуулалт.** Сервер өөрийн үүсгэсэн spawn хуваарьтай
   тулгана. Шалгах зүйлс:
   - Дарсан объект тухайн хуваарьт үнэхээр байсан эсэх
   - Дарсан цаг тухайн объектын амьдрах хугацаанд багтсан эсэх
   - Нэг объектыг давхар дарсан эсэх
   - Нийт хугацаа 20 секундээс хэтрээгүй эсэх
   Аль нэг нь зөрвөл тухайн дарлыг тооцохгүй.
4. **1 утасны дугаар = 1 бүртгэл, 3 оролдлого.**
5. **Оролдлого бүрт шинэ асуултууд** — хариултыг тараах утгагүй болно.
6. `/api/register` дээр IP-ээр rate limit.

## 6. Өгөгдлийн бүтэц

```
registrations
  id              uuid        pk
  last_name       text        not null
  first_name      text        not null
  department      text        not null
  phone           text        not null unique
  invite_code     text        not null unique   -- MLG-202601
  invite_seq      int         not null unique
  attempts_used   int         not null default 0
  best_score      int         not null default 0
  created_at      timestamptz not null default now()

attempts
  id              uuid        pk
  registration_id uuid        fk -> registrations
  status          text        -- 'in_progress' | 'completed' | 'invalid'
  quiz_score      int         not null default 0
  reaction_score  int         not null default 0
  total_score     int         not null default 0
  spawn_schedule  jsonb       -- reaction-ийн хуваарь
  started_at      timestamptz not null default now()
  finished_at     timestamptz

attempt_answers
  id              uuid        pk
  attempt_id      uuid        fk -> attempts
  question_id     int         fk -> questions
  position        int         -- 1..10
  served_at       timestamptz not null
  answered_at     timestamptz
  choice_index    int
  is_correct      bool
  points          int         not null default 0

questions
  id              serial      pk
  text            text        not null
  options         jsonb       not null   -- ["a","b","c","d"]
  correct_index   int         not null
  active          bool        not null default true
```

### Урилгын код үүсгэх

Postgres `SEQUENCE` ашиглана:

```sql
CREATE SEQUENCE invite_seq_counter START 1;
```

Бүртгэл үүсгэх transaction дотор `nextval('invite_seq_counter')` дуудаж
`invite_code = 'MLG-2026' || seq` гэж бүрдүүлнэ. Sequence нь атомар тул
200 хүн нэг зэрэг бүртгүүлсэн ч давхардахгүй.

**Тэмдэглэл:** 99-өөс хойш код `MLG-2026100` болж оронгийн тоо өснө.
Тогтмол өргөнтэй болгохыг хүсвэл padding-ийг нэг мөрөөр өөрчилнө
(`MLG-2026` + 3 оронтой → `MLG-2026001`).

## 7. API

| Route | Юу хийх |
|---|---|
| `POST /api/register` | Бүртгэх эсвэл одоо байгааг олох → `{registrationId, inviteCode, attemptsLeft}` |
| `POST /api/attempt/start` | Оролдлого эхлүүлэх, spawn хуваарь үүсгэх → `{attemptId, spawnSchedule}` |
| `GET /api/attempt/[id]/question` | Дараагийн асуулт (зөв хариултгүй), `served_at` бичнэ |
| `POST /api/attempt/[id]/answer` | Хариулт хүлээн авах, оноо тооцох → `{isCorrect, points}` |
| `POST /api/attempt/[id]/reaction` | Tap-уудыг баталгаажуулж оноо тооцох |
| `POST /api/attempt/[id]/finish` | Дуусгах, best_score шинэчлэх → `{totalScore, rank}` |
| `GET /api/leaderboard` | Эхний 20 |
| `GET /api/invite/[code]` | Урилгын PNG (`@vercel/og`) |
| `GET /admin` | Нууц үгтэй: бүх бүртгэл, CSV татах |

Бүх оноо тооцох логик серверийн талд. Client зөвхөн юу болсныг мэдээлнэ.

## 10. Тест

**Нэгж тест (Vitest):**

- `lib/quiz.ts` — хурдны оноо зөв тооцогдох, хугацаа дуусвал 0
- `lib/reaction.ts` — хуурамч tap (байхгүй объект, хугацаанаас гадуур,
  давхар дарсан) бүгд цуцлагдах
- `lib/scoring.ts` — нийт оноо, тэнцсэн үеийн эрэмбэ
- `lib/invite.ts` — зэрэг дуудахад код давхардахгүй (concurrent тест)

**Интеграцийн тест:**

- Бүртгэл → тоглоом → урилга бүтэн урсгал
- Нэг утсаар 4 дэх оролдлого хийх оролдлого таслагдах
- 200 бүртгэлийг зэрэг үүсгэхэд бүх код өвөрмөц байх

**Гараар шалгах:**

- iPhone Safari + Android Chrome дээр бүтэн урсгал
- Урилгын PNG татагдаж, зөв нэр/код харагдах

## 12. Үлдсэн тодруулга
